## Sobre

Desenvolvo sistemas de IA orientados a produto: agentes com roteamento semântico, RAG, fine-tuning e pipelines multimodais. Os projetos públicos concentram-se em **saúde**, **aquisição de talentos**, **governança de arquitetura** e **tooling para vector DBs**.

No dia a dia: Python/FastAPI, TypeScript, LangGraph/LangChain, ChromaDB, Docker e LLMs locais + cloud.
